# 💖 Hey! — The Question You Can't Say No To

*A tiny page with one big question, two buttons, and one of them has commitment issues.*

**[✨ Try it live](https://abdyevas.github.io/Hangout_website/)**

</div>

## 🎬 How it works

- 💗 Click **Yes**.
- 🏃 Never click **No**.

## 🛠 Built with

Plain **HTML**, **CSS** and **vanilla JavaScript**. No frameworks, no dependencies, no build step.

## 🚀 Run it locally

```bash
git clone https://github.com/abdyevas/Hangout_website.git
cd Hangout_website
```

Open `index.html` in your browser. That's it.

## 📁 Project structure

```
Hangout_website/
├── index.html       # Page structure
├── style.css        # Layout, buttons, heart animation
├── script.js        # Hearts generator and the runaway "No" button
├── hey.jpg          # Main picture
└── wallpaper.jpg    # Background image
```
